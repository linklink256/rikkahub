# Debug长会话内存优化（2026-10-28）

## 改动
1. 通用Markdown（含普通正文/思考）在进入parser/layout之前分段：12Ki字符/120行/单行2048 UTF16 units。上一段/下一段遍历全文，Unicode/CRLF保持；仅显示分段，数据库、发给模型的内容、全文复制/导出不变。跨片段的Markdown结构可能局部不完整。
2. ConversationStore传入权威previous快照；保存时只重编码新增、编辑、移位、分支选择变化的节点。删除处理保留，非session调用仍走全量安全路径；每次只临时编码一条节点，不持有整份已序列化列表。
3. FTS使用previous快照跳过parts未变的消息，避免每次保存读取全历史索引正文。删除、新增及编辑同步；不改变表结构。
4. 团队list_agents只查末节点，而非为每个空闲队友读取完整历史。活动session优先。
5. 默认恒等模板`{{ message }}`直接复用原消息，省掉Pebble/StringWriter整段复制；自定义模板保持原行为。
6. 请求日志开启时，超过16KiB/未知长度/一次性/双向body不再预读取；记录说明而非整段正文。没有改变真正发送的body。

此前未提交的代码块/工具正文分段和provider正文日志修复继续保留。没有修改全局堆上限、强制GC、清聊天、卸载App或修复此前发现的两个agent team权限/并发bug。
